CARDOSO BURGUER HOUSE — versão 3

1. Coloque a sua logo PNG na mesma pasta, com nome exato: logo.png
2. Node.js 24.16+ recomendado.
3. Abra o terminal na pasta e execute:
   npm install
   npm start
4. Abra http://localhost:3000
5. O banco cardoso.db será criado automaticamente.

Observações:
- Não exclua cardoso.db se tiver pedidos salvos.
- Fotos demonstrativas da Unsplash; substitua por fotografias dos próprios produtos antes da publicação.
- Categoria Pão com linguiça aparece, mas ainda sem produto porque preço/descrição não foram enviados.
- Pix online desabilitado até integrar gateway Asaas e validar webhooks/autenticação.
- Um aplicativo da equipe protegido por login e rotas administrativas ainda precisa ser desenvolvido.
- O controle de horários de atendimento e recursos de produção ainda faltam.
